# CSS for Youtube using DarkReader Extension

CSS for cinematic lighting for YouTube using the DarkReader extension in Chrome and Firefox based browsers. 

This CSS code also styles the YouTube buttons to reduce distractions.

Copy and paste the CSS code from the cssyoutube.css file into the DarkReader extension following these steps:
Open DarkReader -> More -> All Settings -> Advanced -> Tools -> The DarkReader Developer Tools window will open.

In the Dynamic Theme Editor, switch to the Per Site Editor tab and search for the URL youtube.com and select it.
Now replace all the existing CSS code with the CSS code from the cssyoutube.css file in this repository and click Apply.

The changes may not be applied immediately.
If this happens, while still on youtube.com, disable DarkReader for YouTube only and reload the website. Then, re-enable DarkReader for YouTube, and the new CSS should now be applied, (You may have to do this process twice for the new CSS style to activate).
